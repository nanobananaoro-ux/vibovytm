# VIBOVYTM — Архитектура проекта

## Стек технологий
- **Framework**: Next.js 15 (App Router, TypeScript)
- **Styling**: Tailwind CSS, Framer Motion (анимации)
- **Backend**: Supabase (PostgreSQL, Auth, Realtime, Storage)
- **Deploy**: Vercel
- **Иконки**: Lucide React
- **Формы**: React Hook Form + Zod
- **Даты**: date-fns

## Схема базы данных (Supabase PostgreSQL)

### Основные таблицы
- `leagues` — лиги (название, слаг, страна, лого, описание)
- `clubs` — клубы (название, лого, город, лига, средняя стоимость состава, история)
- `players` — игроки (имя, возраст, гражданство, позиция, клуб, рыночная стоимость, фото, статистика)
- `player_club_history` — история переходов игрока
- `player_market_value_history` — история изменения рыночной стоимости
- `matches` — матчи (даты, счёт, статус, лига, тур)
- `match_events` — события матчей (голы, жёлтые/красные карточки, замены)
- `news` — новости (заголовок,slug, анонс, контент, категория, дата публикации)
- `achievements` — достижения (типы: клуб/игрок)
- `player_achievements` / `club_achievements` — связи достижений
- `admin_users` — администраторы (email, пароль, код доступа Hoks228, роль)
- `settings` — настройки сайта (ключ-значение)

### RLS (Row Level Security)
- Все таблицы: публичный SELECT для анонимных пользователей
- Новости: SELECT только где `is_published = true`
- Admin tables: полный доступ только для_authenticated администраторов

## Дизайн-система

### Цветовая палитра (тёмно-синий как Transfermarkt)
- **Primary (Background)**: `#0F172A` (slate-900) — główny фон
- **Secondary**: `#1E293B` (slate-800) — карточки, поверхности
- **Accent**: `#3B82F6` (blue-500) — акцент, ссылки, кнопки
- **Accent Hover**: `#2563EB` (blue-600)
- **Text Primary**: `#F8FAFC` (slate-50)
- **Text Secondary**: `#94A3B8` (slate-400)
- **Text Muted**: `#64748B` (slate-500)
- **Border**: `#334155` (slate-700)
- **Success**: `#10B981` (emerald-500)
- **Warning**: `#F59E0B` (amber-500)
- **Danger**: `#EF4444` (red-500)
- **Green accent (из логотипа)**: `#00FF00` — декоративные элементы
- **Red accent (из логотипа)**: `#FF0000` — декоративные элементы

### Типографика
- **Заголовки**: Inter, sans-serif, жирный начертание
- **Основной текст**: Inter, sans-serif, regular/medium
- **Цифры (стоимость, статистика)**: Inter, mono или sans-serif medium

### Компоненты
- `Card` — карточка с тёмным фоном, тонкой рамкой, скруглением
- `Table` — таблица с чёткими границами, наведением подсветки
- `Badge` — метка позиции, статуса, категории
- `Button` — первичная (синяя), вторичная (прозрачная),認 opposition
- `PlayerCard` — карточка игрока с фото, именем, стоимостью, позицией
- `MarketValueBadge` — стоимость с индикатором роста/падения
- `LeagueTable` — tournament table с рангами, очками, результатами
- `AnimatedCounter` — анимированные числа при загрузке

### Анимации
- Фейд-ин при загрузке страниц (Framer Motion)
- Плавный переход между страницами
- Hover-эффекты на карточках и строках таблиц
- Анимация счётчиков стоимости
- Скелетоны для загрузки данных
